A $5 device that hears Indian speech and performs a verified action, offline, forever.

Move the constraint from the model to the decoder. One core. Many instruction sets. The task compiles to a grammar; the grammar is the instruction set, so nothing task-specific is baked into the weights.

The problem, measured

55%

of the 455 teams that built voice agents abandoned the project. Top reason: first-turn understanding.

85%

drive-thru voice AI accuracy, against 89-92% for humans. IVR abandonment 38%, and 67% of calls escalate anyway.

50%+

speech-to-text error in real Indian fields, from dialect, slang and noise.

Every one of those systems answers in an open vocabulary. The failure lives in the gap between what was heard and what was executed.

The move

Move the constraint from the model to the decoder.

A byte-level grammar compiled from the target's own schemas constrains every decoded token, so the action is well-formed by construction, in any script. A garbled utterance can only produce a valid action or a refusal. Never a wrong one.

  • Guardrail, audit trail and refusal become architecture, not aspiration.
  • The grammar becomes the localisation layer: date formats, numeral systems, currency units and enum members live in the grammar, so the model never has to learn them.
  • A wrong pesticide dosage can destroy a crop. A wrong call can be made structurally impossible.

The three contributions

  • Per-language subnetwork lattice. Tamil pays for 4 layers, code-mixed Hindi pays for 16. One download, 13 scripts.
  • Grammar as instruction set. One core, one compiled dialect per app.
  • Refusal as a first-class output, calibrated per script, in the user's own register.

The gap nobody has built

Bhashini has $600M for 100 Indian LLMs. FarmerChat has 1M+ users and 30,000 hours of farm audio. Farm Vaidya has 5,000 crop Q&A across 100+ crops. The drive-thru industry has 85% accuracy at $0.08-0.20 per minute. NCMS already fields an offline AI-server at TRL-6 with no cloud connectivity in disconnected environments.

Offline + $5 + grammar-safe + Indic + zero marginal cost. Every hard component to build it is already open.
